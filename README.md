# MAK CONNECT — Site

Site institucional da **MAK CONNECT**, assessoria e gestão de carreira para influenciadoras digitais (São Paulo).

Site estático (HTML, CSS e JavaScript puros), sem etapa de build. Para ver localmente, abra `index.html` no navegador.

## Seções
Hero 3D · Sobre (missão e visão) · Influenciadoras / Marcas · Método MAK · Valores · Boutique · Contato

## Pendências
- Trocar `[SEU E-MAIL]` e `[@SEU INSTAGRAM]` no rodapé (`index.html`) e em `CONTACT_EMAIL` (`script.js`).
- O formulário de contato abre o app de e-mail do visitante. Para receber mensagens direto, ligue-o a um serviço como Formspree ou Netlify Forms.
