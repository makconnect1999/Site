# MAK CONNECT — Site

Site institucional da **MAK CONNECT**, assessoria e gestão de carreira para influenciadoras digitais (São Paulo).

Site estático (HTML, CSS e JavaScript puros), sem etapa de build. Para ver localmente, abra `index.html` no navegador.
