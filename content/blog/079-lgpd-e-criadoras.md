Criadoras lidam com dados pessoais com mais frequência do que imaginam: inscrições em sorteios, formulários de pesquisa, listas de e-mail, cadastros para eventos, mensagens com informações pessoais. A Lei Geral de Proteção de Dados Pessoais, a LGPD, estabelece regras para o uso dessas informações no Brasil.

> Este texto é informativo e não substitui orientação jurídica. Para estruturar processos que envolvem dados, procure apoio especializado.

## O que são dados pessoais

Qualquer informação que identifique ou possa identificar uma pessoa: nome, e-mail, telefone, endereço, documento, foto, entre outros. Alguns dados são considerados sensíveis, como informações de saúde, e exigem cuidado ainda maior.

## Princípios básicos

### Finalidade
Colete dados para um objetivo claro e informado. Se você pediu o e-mail para um sorteio, não use para outra coisa sem que a pessoa saiba.

### Necessidade
Peça apenas os dados de que realmente precisa. Para enviar uma newsletter, o e-mail basta; não é preciso CPF.

### Transparência
Explique, de forma simples, o que será feito com os dados, por quanto tempo serão guardados e com quem serão compartilhados.

### Segurança
Guarde as informações em locais protegidos, com senha e acesso restrito.

### Direitos das pessoas
As pessoas podem pedir para saber quais dados você tem, corrigir ou excluir. Tenha um canal para isso.

## Situações comuns

### Sorteios
Explique quais dados serão coletados, para quê e se serão compartilhados com a marca parceira. Não peça dados além do necessário. Sorteios também podem ter regras específicas de autorização, conforme o formato.

### Listas de e-mail
Envie mensagens apenas para quem se inscreveu e ofereça uma forma simples de cancelar.

### Pesquisas
Se a pesquisa não precisa identificar ninguém, faça de forma anônima.

### Mensagens privadas
Não compartilhe prints com dados de seguidores sem autorização.

### Parcerias com marcas
Se a marca quer receber dados do seu público, por exemplo de participantes de uma ação, isso precisa estar claro para as pessoas e bem definido no contrato.

## Boas práticas

- Use ferramentas confiáveis para formulários e listas.
- Apague dados que não são mais necessários.
- Não compre nem venda listas de contatos.
- Tenha um texto simples de privacidade para ações que coletam dados.

## Resumo

A LGPD exige finalidade clara, coleta do mínimo necessário, transparência, segurança e respeito aos direitos das pessoas. Para criadoras, isso se aplica a sorteios, listas, pesquisas e parcerias. Cuidar dos dados do público é também cuidar da confiança.
